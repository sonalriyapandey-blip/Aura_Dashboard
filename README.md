# Aura_Dashboard

PowerBIDashboard
Aura Analytics Dashboard | Power BI

📊 Project Overview

This project presents an interactive Aura Analytics Dashboard developed using Microsoft Power BI to analyze overall sales performance, profit, order volume, product categories, regional performance, and customer segments. The dashboard transforms raw sales data into meaningful visual insights to support data-driven business decisions.

Key Features & Dashboard Values
Total Profit: 27.45K
Total Sales: ₹294.53K
Unique Orders: 711
Total Quantity Sold: 5K
Profit by Region: Compares profit across West, East, Central, and South regions, with the West region showing the highest profit in the displayed chart.
Sales by Segment: Analyzes sales distribution across Consumer, Corporate, and Home Office segments.
Sales by Year & Month: Displays monthly sales trends to identify fluctuations and changes in business performance over time.
Sales by Category: Compares sales across Technology, Office Supplies, and Furniture categories, with Technology leading in the displayed chart.

Objective

The main objective of this project is to analyze business performance, track key performance indicators (KPIs), identify high-performing regions and product categories, understand customer segment contributions, and monitor sales trends through an interactive dashboard.
